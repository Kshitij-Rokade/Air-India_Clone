AIR INDIA-INSPIRED VISUAL CLONE (HTML + CSS ONLY)

Files:
- index.html: page structure and placeholder visual content
- style.css: styling and responsive layouts

How to run:
1. Keep index.html and style.css in the same folder.
2. Open index.html in a browser, or use Live Server in VS Code.

Notes:
- This is a visual learning demo, not an official Air India website.
- Booking controls, links, tabs and buttons are visual placeholders only.
- Images are loaded from Unsplash and Google Fonts is used for typography, so internet access is needed for those assets.
- The logo is a text/symbol approximation. Use only assets you have permission to use if publishing.
